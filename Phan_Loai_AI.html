🗂️ Trạm Phân Loại & Đẩy File Lên Drive

Giải phóng ổ đĩa bị báo đỏ - Giữ lại mã nguồn Python
💡 Luật phân loại thông minh:
• File Database (.db, .sql) & File nén: Tự động CẮT và CHUYỂN thẳng lên Google Drive (Xóa sạch dưới máy để trống ổ đĩa).
• File Python (.py, .bat): Chỉ COPY lên Drive để sao lưu, vẫn giữ lại bản gốc dưới máy để bạn chạy bình thường.
